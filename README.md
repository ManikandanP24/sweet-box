# Sweet Box Run 3D

React Three Fiber endless runner using the provided character face. Includes sweet collections, lane changes, jumping, sliding, power-ups, obstacles, delivery riders, and a tanker chase.

## Run locally
`cd web && npm install && npm run dev`

## Android APK
Open GitHub Actions → **Build Sweet Box Run 3D APK**, then download **Sweet-Box-Run-3D-APK** and extract `app-debug.apk`.

## Website
The deployment workflow publishes `web/dist` to `gh-pages`. Set repository **Settings → Pages → Deploy from a branch → gh-pages / (root)** once if Pages is not enabled.

Desktop: arrow keys / WASD, Space to jump, Down to slide, P/Esc to pause. Mobile: swipe to move, jump or slide.
